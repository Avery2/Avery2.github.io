The web

The web is experienced locally even when its structure is planetary.

AI-generated exampleThis is substantive prototype content written to test the linked-reading interface, not Avery’s published writing.

The web is described as a network, but a person usually experiences it as a sequence of documents. Links expose adjacent possibilities; the browser chooses one and records the movement in history.

This local experience is a strength. We do not need a map of the entire web before reading one page. Hypertext works because global structure can remain underneath while a single path becomes temporarily meaningful.
