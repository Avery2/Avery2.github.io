Information architecture

Information architecture shapes possible relationships before it chooses a visible route.

Information architecture is often expressed as a hierarchy because trees are easy to draw and administer. But concepts routinely belong in several contexts at once. A graph can represent those associations without forcing one canonical parent.

The visible interface need not display that whole graph. A reader can encounter one active path through native links, while the system keeps the larger set of relationships underneath. Compare maps and interface navigation.
