# `/writing/` deployment mount

Writing source and the linked-reading engine live in [`Avery2/writing`](https://github.com/Avery2/writing). That repository is a GitHub Pages project site and directly owns the public `/writing/` URL prefix.

This repository contains only portfolio-owned source snapshots that also use the `/writing/` URL namespace:

- `experience/` and `education/` are generated from resume data, then copied into the writing Pages artifact for compatibility.
- Homepage entry points are curated manually in `data/manual-tiles.yml`.

Do not add prose, note Markdown, or a second writing compiler here.
