# `/writing/` deployment mount

Writing source and the linked-reading engine live in [`Avery2/writing`](https://github.com/Avery2/writing). That repository is a GitHub Pages project site and directly owns the public `/writing/` URL prefix.

This repository does not own content beneath that URL namespace. Experience and education are Markdown sources in `Avery2/writing`; their established routes are generated and deployed there. This portfolio only extracts résumé metadata for cards and curates homepage entry points in `data/manual-tiles.yml`.

Do not add prose, note Markdown, or a second writing compiler here.
